# Club Alpha site

Informational landing page for Club Alpha, a ReRev Labs student founder program in Birmingham, AL.

- `index.html` is the whole site. No build step.
- `netlify.toml` tells Netlify to publish the repo root.

## Deploy

1. Netlify > Add new site > Import an existing project > GitHub > pick this repo.
2. Leave the build command empty.
3. Set the publish directory to `.`
4. Click Deploy.

Every push to `main` redeploys the site.
